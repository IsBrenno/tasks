# Gerenciador de Tarefas

Este projeto será usado para arpender e praticar conceitos de JAVA e OOP de forma pratica e intuitiva.

A estrutura do projeto está sujeito a alterações conforme a evolução do projeto e do conhecimento do autor na linguagem JAVA.


Etapas a serem feitas durante o Projeto:

1. Toda a aplicação rodando em memória.
2. Persistencia dos dados com file handling.
3. Persisteência dos dados com banco de dados.
4. Projeto será transformara em web usando Springboot.
5. Criação do front end em html, css e js puros.
6. Ultilização do angular para criação do front end.
